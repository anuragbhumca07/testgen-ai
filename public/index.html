The Challenge

COBOL Testing Is Broken

Legacy annuity systems process billions in premium each year — yet QA relies on manual, error-prone, undocumented test design.

Weeks of Manual Work

A single enhancement BSD takes 1–2 weeks to manually translate into a test suite. With dozens of modules releasing quarterly, teams are perpetually behind.

Missed Edge Cases

Boundary values, COMP-3 rounding, free-look periods, qualified-plan tax rules — manual test designers miss critical edge cases that slip into production.

Zero Traceability

Auditors demand a clear link from every business rule to a test case and expected result. Manual spreadsheets can't provide it — compliance risk is real.

The Solution

AI That Understands COBOL Logic

TestGen AI reads your actual code — not a description of it — and produces verified, traceable test cases with computed expected values.

Reads BSD + COBOL Source

Ingests your Business Systems Design and actual .cbl / .cpy files. No manual input, no proxy documents.

Computes Expected Values from Code

Traces every COMPUTE statement. Shows arithmetic step-by-step. COMP-3 precision, ROUNDED clauses — all honored.

Full Traceability Matrix

Every test case cites the BR it covers. Every BR points to test IDs. Every error code has a negative test. Ready for audit.

Formal Documentation Auto-Generated

Outputs a complete test plan with RTM, environment setup, execution notes, and sign-off block — attach directly to your change record.

Process

Six Phases. One Complete Suite.

A deterministic, standards-driven process that runs end-to-end — from reading your BSD to emitting signed-off documentation.

1

Ingest & Inventory

Reads every module, copybook, and the BSD. Maps COPY relationships, CALL chains, and linkage sections. Flags any missing inputs explicitly.

Input Analysis
2

Data Domain Extraction

Extracts PIC clauses, COMP-3 fields, 88-levels, signed/unsigned fields, and implied decimals into a typed field catalog.

Field Catalog
3

Rule & Path Analysis

Extracts every BR from the BSD and every branch (IF / EVALUATE / 88-level) from the code. Reconciles them — flags any gaps.

Gap Detection
4

Test Case Design

Applies EP, BVA, Decision-table, State-transition, and Annuity Domain techniques. Guarantees every BR and every error code is covered.

Coverage Design
5

Expected-Result Computation

Executes COBOL logic symbolically. Shows arithmetic step-by-step. Respects ROUNDED, truncation, and COMP-3 precision. Never guesses.

Math Verification
6

Self-Review Pass

Critiques its own suite: checks BR ↔ test coverage table for blank cells, validates input values fit PIC clauses, adds missing cases.

Quality Assurance
